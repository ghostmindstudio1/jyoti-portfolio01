JYOTI PORTFOLIO — EASY EDITING GUIDE

1. Open Jyoti_Video_Editor_Portfolio.html in VS Code.
2. Use Ctrl+F to search for the text you want to change.
3. Save with Ctrl+S and refresh the HTML in Chrome.

VIDEO TITLES / LINKS
Search for the current video title and edit the <h3> text.
For a video link, search for its Google Drive ID inside data-src=".../preview".

IMAGE FILES
The images are now separate files in the assets folder. This makes replacing them much easier.
Use the matching src="assets/image_X.ext" in the HTML.

IMPORTANT
Keep the assets folder beside the HTML file. Do not move the HTML alone unless you also copy the assets folder.

For major layout/JavaScript changes, make a backup first.
